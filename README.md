# Projeto GPT - Interface de Inteligência Artificial 🤖

Este projeto foi desenvolvido como parte do curso **Microsoft Azure AI Fundamentals (AI-900)**. Ele consiste em uma interface web moderna e responsiva que se conecta a modelos de linguagem (GPT) para simular um chat inteligente.

O foco do projeto foi aplicar conhecimentos de IA da Microsoft, integrando uma interface amigável com serviços cognitivos.

## 🌟 Funcionalidades

- **Interface de Chat:** Design inspirado em aplicações modernas de conversação.
- **Integração com IA:** Consumo de modelos generativos para respostas em tempo real.
- **Responsividade:** Adaptado para diferentes tamanhos de tela (Desktop e Mobile).
- **Backend Node.js:** Servidor intermediário para comunicação segura com APIs de IA.
